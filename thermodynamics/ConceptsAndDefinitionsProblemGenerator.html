How to use

Pick a problem type and press New problem. Enter your answers and press Check answers; numerical answers are accepted within 2%. Show the solution when you are done. Every problem has a seed number in the page address, so a link to it brings up the same problem for anyone you share it with. SI units are used throughout. Property data are computed in the page, so the tables of a thermodynamics text are not needed, although they give the same values.
